# How to make k8s persist data?

Note:
- a container is ephemeral, ie. it doesn't store any data, so once it is deleted, it gets lost!
- so in order for a container to store data, it needs to have a volume or a disk mounted to it
- the volume is just a piece of the file system, ex- a file
