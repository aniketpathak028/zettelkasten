# PARA Method

- system conceived by Tiago Forte
- way to structure notes/life/thought-process

## P - Projects

- short term collection of tasks and notes
- ex- create a garden in the balcony
	- buy pot
	- buy earth
	- buy seeds ....
- collecting information in the folder

## A - Areas

- something you're responsible for a longer pd of time
- ongoing engagement or responsibility
- ex - House 
	- responsible for maintenance
	- make sure the roof doesn't leak
	- regular painting

## R - Resources

- collection of information which you expect to be useful in the future
- reference, things you expect to come back to later
- ex - a hiking trip you found in Norway, that you might want to ref later

## A - Archive

- notes which are not useful currently or in the near future, but which you don't want to throw away either
